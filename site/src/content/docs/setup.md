## Prerequisites

Use Node 24 LTS and npm for the documentation site. The Python course baseline is Python 3.13 (supported range `>=3.13,<3.15`) managed with `uv`.

From the repository root, create the Python environment with `uv sync`, then run the API using the command shown in the project README.

The documentation site lives in `site/`. Run `npm install` and `npm run dev` there to preview these lessons locally.
